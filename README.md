# Homebrew tap for Gantry

```sh
brew install --cask pigeoonn/gantry/gantry
```

Installs the `rig` command of [Gantry](https://github.com/pigeoonn/gantry) (Apple Silicon). Gantry is beta software; on macOS it has had much less testing than on Linux. It needs a Chromium based browser (Chrome, Brave, Edge) for its window.

The build is not signed by Apple, so macOS may ask you to allow it the first time (System Settings, Privacy & Security).
